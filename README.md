# PDF RAG Chatbot (LangChain + Chroma + Google Gemini)

Chat with your local PDFs using Retrieval-Augmented Generation:
- **Chroma** — vector database (local, persists to disk)
- **Local sentence-transformers model** — embeddings (free, runs on your
  machine, no API key or per-call cost)
- **Google Gemini (free API tier)** — answers your questions using
  retrieved context

No Ollama, no Anthropic billing required. Only the final question-answering
step calls the Gemini API; embeddings and vector search are entirely local.

## 1. Prerequisites

- Python 3.10+
- A free Google API key — get one at https://aistudio.google.com/apikey
  (sign in with any Google account; no credit card required for the free
  tier)

## 2. Setup

```powershell
cd PdfRagChatbot_Gemini
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## 3. Set your API key

Copy `.env` to `.env` and fill in your key:

```powershell
copy .env.example .env
notepad .env
```

`.env` should contain:
```
GOOGLE_API_KEY=AIza-your-real-key-here
```

Both scripts load this automatically via `python-dotenv`.

**Double-check the file is really named `.env`, not `.env.txt`** — Windows
often hides extensions. Verify with:
```powershell
dir /a
```

## 4. Put your PDFs in place

Default folder: `D:\pdf`. Or point elsewhere:

```powershell
$env:PDF_DIR="D:\MyOtherPDFs"
```

## 5. Build the vector database

```powershell
python ingest.py
```

Loads your PDFs, splits them into chunks, embeds them locally, and writes
everything to `chroma_db/`. Re-run any time you add/change PDFs — it
rebuilds from scratch each time.

## 6. Run the chat app

```powershell
streamlit run app.py
```

Opens at `http://localhost:8501`. Ask questions about your PDFs; each
answer has an expandable "Sources" section (file + page), generated by
Gemini.

## About the free tier

Google's Gemini API free tier (via AI Studio / `aistudio.google.com`) gives
a generous number of free requests per day for Flash-tier models, with
rate limits (requests per minute and per day). For personal/testing use —
asking questions about your own PDFs — this comfortably stays within the
free quota. If you ever see a `429` rate-limit error, just wait a minute
and try again, or check current limits at https://ai.google.dev/gemini-api/docs/rate-limits

## Configuration (environment variables, all optional except the API key)

| Variable            | Default                                    | Meaning                              |
|-----------------------|----------------------------------------------|-----------------------------------------|
| `GOOGLE_API_KEY`     | *(required)*                                 | Your Google AI Studio API key          |
| `PDF_DIR`            | `D:\pdf`                                     | Folder to scan for PDFs (ingest.py)    |
| `CHROMA_DIR`         | `chroma_db`                                  | Where the Chroma DB is stored          |
| `COLLECTION_NAME`    | `pdf_docs`                                    | Chroma collection name                 |
| `EMBED_MODEL`        | `sentence-transformers/all-MiniLM-L6-v2`     | Local embedding model                  |
| `LLM_MODEL`          | `gemini-flash-latest`                        | Gemini model alias used for answers    |

`gemini-flash-latest` is a Google-maintained alias that always points at
their current recommended fast model, so this project keeps working even
as Google renames or upgrades things. If you want a specific pinned model
instead (e.g. for reproducibility), set `LLM_MODEL` to an exact model name
from https://ai.google.dev/gemini-api/docs/models

## Troubleshooting

- **"GOOGLE_API_KEY environment variable is not set"** — check `.env`
  exists in this exact folder (not `.env.txt`) and contains a valid key,
  or set the environment variable directly:
  ```powershell
  $env:GOOGLE_API_KEY="AIza-your-real-key-here"
  ```
- **"No Chroma DB found (or it's empty)"** — run `python ingest.py` first,
  from the same working directory you'll later launch `streamlit run app.py`
  from.
- **`429` rate limit error** — you've hit the free tier's requests-per-minute
  or requests-per-day limit. Wait a bit and retry, or check your usage at
  https://aistudio.google.com/
- **Authentication/permission error from Gemini** — confirm the key was
  copied in full and is still active at https://aistudio.google.com/apikey
- **Slow first run of `ingest.py`** — the local embedding model downloads
  once (~90MB); subsequent runs are fast.
- **"missing ScriptRunContext" warning** — you ran `python app.py` directly.
  Always use `streamlit run app.py`.
